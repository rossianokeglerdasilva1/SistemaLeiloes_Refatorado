# Sistema de Leilões (Versão Refatorada)

Aplicação desenvolvida para informatizar e gerenciar as rotinas operacionais de uma casa de leilões.

**Melhorias desta versão:**
* Implementação de boas práticas de segurança e controle de versão.
* Configuração de arquivo `.gitignore` para isolamento de dados sensíveis e credenciais de banco de dados.

**Tecnologias utilizadas:**
* Java
* MySQL
